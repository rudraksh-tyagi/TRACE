# Role 2 — GIS Vectorization & Spatial Handoff Module

---

## Overview

This module ingests binary SAR detection raster masks generated by Role 1, extracts georeferenced vector polygon boundaries, computes high-precision spatial metrics (area, perimeter, bounding box, centroid), and formats standardized GeoJSON outputs for Role 3 (Drift Modeling) and Role 4 (AIS Correlation).

## Pipeline Workflow

* **Raster Mask Ingestion**: Reads binary raster masks (`oil_mask.tif`) and linked detection parameters (`detection_metadata.json`) generated by the detection module.
* **Boundary Extraction**: Applies contour polygon extraction to convert pixel clusters (value = 1) into spatial shapes using Rasterio and Shapely.
* **CRS Coordinate Transformation**: Reprojects local raster spatial boundaries into WGS84 (`EPSG:4326`) latitude/longitude decimal degrees.
* **Geospatial Metric Engine**: Computes physical surface area (sq km) via Mollweide Equal Area projection (`ESRI:54009`), boundary perimeter (km), polygon centroid, and spatial bounding boxes.
* **Output Contract**: Exports a standardized `spill_polygons.geojson` payload containing all spatial geometries and linked detection metadata ready for drift simulation and vessel attribution.

---

## Output Contract Specification (`spill_polygons.geojson`)

* `spill_id`: Unique identifier assigned to each detected slick (e.g., `spill_001`).
* `area_km2`: Physical slick area calculated using equal-area spatial projection.
* `perimeter_km`: Total boundary length of the spill slick in kilometers.
* `centroid_lon_lat`: Center coordinate array `[Longitude, Latitude]` for quick location targeting.
* `bbox_minx_miny_maxx_maxy`: Bounding box extent `[Min_Lon, Min_Lat, Max_Lon, Max_Lat]`.
* `source_image` & `threshold_db`: Origin parameters directly mapped from Role 1 for complete lineage.
